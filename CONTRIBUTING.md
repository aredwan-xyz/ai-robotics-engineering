# Contributing to Awesome Physical Intelligence

First, thank you for wanting to make this better. This project lives and dies by community quality.

## What Makes a Good Contribution

### Resources worth adding
- You've personally used it and found it genuinely valuable
- It covers something not already represented
- It's maintained and up-to-date (check last commit/update date)
- Free > paid when quality is equivalent

### Resources we'll reject
- Affiliate or referral links (zero tolerance)
- Sponsored content or promotional material
- Abandoned projects (>2 years no activity, unless historically significant)
- Resources that duplicate existing ones without being meaningfully better
- Anything you haven't actually tried

## Formatting

Every resource entry follows this format:
```markdown
- [Resource Name](URL) — One-line description of what it is and why it's valuable
```

For code snippets:
- Use fenced code blocks with language annotation
- Runnable > pseudocode
- Add comments only where non-obvious

For difficulty ratings:
- ⬜ Beginner: No prior domain knowledge assumed
- 🟦 Intermediate: Solid fundamentals, some project experience
- 🟥 Advanced: Strong background, research-adjacent

## How to Submit

1. Fork the repository
2. Create a branch: `git checkout -b add/your-resource-name`
3. Make your change
4. Verify links work: `linkcheck README.md` (or manually check)
5. Open a PR with:
   - What you're adding
   - Why it belongs here
   - Your personal experience with it

Simple: be a good engineer. Disagree with the content, never with the person. PRs are about quality, not status.

## Maintainers

PRs are reviewed within 1 week. If it's been longer, ping via an issue.
